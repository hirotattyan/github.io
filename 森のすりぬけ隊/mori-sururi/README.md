# 森のすりぬけ隊 / FOREST DODGE CLUB

猪と虎が岩と予告付きの銃弾を避け、生存時間を競う独立したブラウザゲームです。企画・試遊・改善指示：ひろたっちゃん／コード・オリジナルSVGキャラクター制作：AI。

## 起動
フォルダを展開し、index.htmlをブラウザで開いてください。HTMLだけを別の場所に移動しないでください。外部ライブラリ、ビルド、ログイン、APIは不要です。BGMは初期オフです。

## 操作
ゲーム盤面内はiPhone向けの文字選択・長押しメニュー・画像ドラッグを抑止しています。プレイ中の1本指タッチではブラウザ既定動作も抑えます。ページ全体の文字選択や拡大を一律に禁止していません。iPhone実機での長押し表示は未確認です。
スマホは盤面のどこからでもドラッグ。触れた位置には飛ばず、指の移動量に応じて移動目標が動きます。キャラクターは速度上限に従って目標を追います。指を離すと停止します。キャラクターから離れた場所を触ると指で隠れにくく操作できます。
PCは矢印キーまたはWASD。斜め移動の速度は通常移動と同じです。Escapeでも一時停止できます。

## 相棒とルール
猪：体力5、速さ165（ゲーム内の距離/秒）。虎：体力3、速さ214.5（猪の1.3倍）。両者の当たり判定は同じ半径11で、描画サイズ56×56より小さくしています。
岩は−1、銃弾は−2。ダメージ後は1秒無敵で、輪郭と半透明で表示します。
木の実は＋1回復。満タンなら触れても取得せず、そのまま流れます。最大値を超えません。
最初の15秒は岩のみ。その後は端の照準と点線が0.8秒出てから銃弾が発射されます。予告開始時のプレイヤー位置を狙い、予告中も発射後も追尾しません。
20秒ごとに難易度が上がり、LV 6で上限です。岩は同時最大10個、銃弾は30秒未満で同時最大2発、30秒以降で最大4発。予告は最大2方向同時です。30秒から単発と2方向を交互に出し、60秒以降は毎回2方向になります。各予告は異なる画面端から、55〜140度離れた方向で同時に開始・発射します。正反対からの挟み撃ちと130未満の至近距離予告は避けます。岩は5つの横位置から選び、20秒以降は最大左右60の速度で斜めにも流れ、端では反射します。出現直後の密集とプレイヤー直近への出現を抑えます。岩の縦速度68〜148、銃弾270〜370、銃弾予告の間隔は3.1秒から最短1.6秒へ短縮です。
木の実は最初6秒後、その後12〜16秒間隔で低頻度に出現します。
生存1秒につき10点（小数切り捨て）。一時停止中は障害物、予告、無敵時間、経過時間とスコアがすべて止まります。

## 記録
猪と虎それぞれの上位5スコアと生存時間をlocalStorageに保存します。同点は生存時間の長い順です。1プレイに固有IDを付け、5秒ごと・一時停止・終了時は同じ記録を更新するので、停止と再開で件数が増えることはありません。途中で相棒選択へ戻った場合も、その時点までの記録を残します。従来の最高生存時間は各相棒1件の記録として引き継ぎます。ブラウザや配信元が変わると記録は別になります。ブラウザのデータ削除で記録は消えます。保存できない環境では画面上で知らせます。

## ファイル構成
- index.html：画面・遊び方
- style.css：デザインとスマホ対応
- engine.js：移動・当たり判定・出現・ダメージ・回復
- script.js：描画・入力・画面切り替え・最高記録
- records.js：相棒ごとの上位5スコア・重複防止・旧記録の移行
- music.js：オリジナルBGMの端末内合成・再生制御
- effects.js：被弾・回復・銃弾発射の効果音合成・再生制御
- assets/boar.svg：オリジナルの猪
- assets/tiger.svg：オリジナルの虎
- assets/hirotatchan-logo.png：支給ロゴ。フッターの制作クレジットに配置し、元画像は変更せず余白と背景へのなじみをCSSで調整。
- assets/title-logo.png：ゲーム専用の透過タイトルロゴ。猪・虎と木の葉をあしらったオリジナル画像を画像生成機能で制作。

## 検証済み
Node.jsによるゲーム処理テスト：体力差、1.3倍の速度差、同じ当たり判定、斜め移動の正規化、相対ドラッグと速度上限、指を離した後の停止、移動範囲、岩−1／弾−2／実＋1、満タンの実の保持、無敵1秒、0.8秒予告と固定方向、非追尾、一時停止中の全状態凍結、15秒後の銃弾解禁、難易度上限、ゲームオーバーと再挑戦の完全初期化。速い弾がフレーム間ですり抜けないよう、移動経路の当たり判定も確認。
模擬UIテスト：選択・開始・一時停止・再開・終了・再挑戦・選択に戻る。30回開始してもアニメーション処理が1本。別タブで停止し、戻っても手動再開。相対ポインター操作、画面サイズ変更時の範囲、キャラクター別の記録保存。SVG構文とHTML参照先も確認。

## BGM
森の散歩をイメージした112 BPM、約34.3秒のオリジナルループ。木琴風の音、柔らかい笛風メロディ、弦を弾いたような低音をWeb Audio APIで端末内合成します。外部音源や通信は不要です。初期オフ、音量調整あり。プレイ中のみ再生。一時停止・選択画面・別タブ・終了で停止し、手動再開時は続きから、再挑戦時は先頭から再生します。実機での試聴は未確認です。

## 効果音
初期オフ、BGMと独立してオン・オフと音量を調整できます。被弾時は短い低音、実際に体力が増えたときは上昇するチャイム、銃弾の実発射時は短いノイズ音。予告開始・無敵中の接触・満タン時の木の実接触では鳴りません。2発同時発射は1つのステレオ音で表現し、過度な音量の重なりを防ぎます。イベントを消費する方式で、同じイベントを繰り返し再生しません。一時停止・タブ移動・再挑戦・選択画面で停止します。終了を招いた被弾音は最後まで再生します。effects.jsも設置してください。実機での試聴は未確認です。

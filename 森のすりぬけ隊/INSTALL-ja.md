# 森のすりぬけ隊 — 設置手順

完成版のゲーム一式です。既存ポートフォリオのファイルは含めていません。

## 弟へ：GitHub Pagesに載せる

1. ZIPを展開します。
2. `mori-sururi` フォルダを、ポートフォリオの公開元の `index.html` と同じ階層へ、フォルダごとコピーします。中のファイルは省かず、名前も変えないでください。
3. ポートフォリオの好きな場所に次のリンクを追加します。

```html
<a href="./mori-sururi/">森のすりぬけ隊で遊ぶ</a>
```

4. GitHubへコミット・プッシュし、Pagesの公開完了を待ちます。公開済みのポートフォリオからリンクを開いて確認してください。閲覧者のログインは不要です。

GitHub Pagesで公開するフォルダが `docs` なら、その中へコピーします。ゲームには `../index.html` への「ポートフォリオに戻る」リンクを付けています。違う階層に設置する場合は、ゲームの `index.html` 内のこのリンク先を変更してください。

## 手元で遊ぶ

`mori-sururi/index.html` をブラウザで開きます。HTMLだけを抜き出さず、フォルダ一式を保ってください。公開時と手元では記録が別になります。

## 操作とルール

スマホは盤面のどこからでもドラッグ、PCは矢印キー／WASDで移動します。猪は体力5、虎は体力3で足が速い相棒です。岩と銃弾を避け、木の実で回復しながら生存時間を競います。BGMと効果音は初期オフで、画面のボタンからオンにできます。

## 記録・音・素材

- 猪・虎それぞれの上位5記録を同じブラウザ内に保存します。サーバーへの送信はありません。ブラウザのデータを消すと記録も消えます。
- BGMと効果音はJavaScriptで端末内合成するため、音声ファイルはありません。`music.js` と `effects.js` が必要です。
- タイトルロゴ、支給のひろたっちゃんロゴ、オリジナルの猪・虎の画像は `assets` に同梱しています。
- 外部ライブラリ・ビルド・APIキー・ログインは不要です。ゲーム本体の細かな仕様は同梱の `README.md` を参照してください。

## 動作確認

自動テストで移動・体力差・当たり判定・回復・無敵時間・固定方向の銃弾予告・段階的な難易度・一時停止・再挑戦の初期化・処理の重複防止・上位5記録・音の制御を確認しています。

公開先での実機確認は未実施です。設置後、スマホとPCで表示、ドラッグ、長押し時の選択抑止、音量、タブ移動時の停止、再挑戦、記録の再読み込みを最終確認してください。

## 更新するとき

ゲームのフォルダ一式を差し替えます。既存ポートフォリオを丸ごと置き換える必要はありません。保存キーと公開先が同じなら、通常のファイル更新で記録は残ります。

# 弟への引き継ぎ：イロクミ

このZIPは、既存のGitHub Pagesポートフォリオへ追加するための完成データです。制作・設置担当は弟です。試遊用URLやChatGPTへのログインは不要です。現在のポートフォリオは変更していません。

## まず遊ぶ
ZIPを展開し、irokumiフォルダのindex.htmlをMacのSafariまたはChromeで開いてください。HTMLファイルだけを別の場所へ移動しないでください。BGMと効果音は初期オフなので、各ボタンを押してオンにします。音源はJavaScriptで生成するためMP3ファイルはありません。

## GitHub Pagesへ設置する
1. ポートフォリオのリポジトリをVS Code等で開きます。
2. ポートフォリオのトップページindex.htmlと同じ階層に、ZIP内のirokumiフォルダを丸ごと置きます。既存ファイルは上書きしません。
3. ポートフォリオの作品紹介欄に、次のリンクを追加します。

```html
<a href="./irokumi/">イロクミで遊ぶ</a>
```

4. GitHubへコミット・プッシュし、GitHub Pagesの公開処理が終わるのを待ちます。
5. 公開先のゲームURLを開き、動作を確認します。

現在のポートフォリオURLにそのまま追加した場合、ゲームの公開先は以下になる想定です（まだ設置・公開していません）。
https://hirotattyan.github.io/github.io/irokumi/

公開後はこのURLを共有すれば、相手はログインせずに遊べます。現在の試遊用URLへのリンクを貼るだけでは、このファイルの設置にはなりません。

## 公開用の調整
このパッケージでは「遊べる試作品」を「ブラウザパズル」に変更し、制作ファイルのダウンロードリンクを外しています。ゲーム下部には「ポートフォリオに戻る」を追加してあり、リンク先は../index.htmlです。別の階層に設置する場合は、このリンクと紹介欄のリンクを設置場所に合わせて変更してください。

## 同梱ファイル
- index.html：画面・遊び方
- style.css：デザイン
- engine.js：交換・消去・連鎖・せり上がり
- script.js：スライド操作・描画・記録
- music.js：BGM1〜3（開始・再挑戦ごとにランダム）
- effects.js：消去・連鎖・天井カウント音
- hirotatchan-logo.png：支給ロゴ

追加ソフトのインストール、ビルド、サーバー処理、外部API、認証設定は不要です。BGMの手動選曲はありません。同じ曲が続く場合もあります。

## 公開前に弟が実機確認すること
- スマホ：左右スライド・空きマス交換・スクロールの誤動作がないか
- PC：ドラッグ・表示・ロゴの見切れがないか
- 消去・落下・連鎖・天井でのゲームオーバー
- 一時停止・再開・別タブ移動・再挑戦
- BGM・効果音・カウント音・それぞれの音量
- 最高記録の保存と「ポートフォリオに戻る」リンク

ロジック・模擬操作の自動確認は実施済みですが、各実機での表示と試聴は未確認です。最高記録はブラウザと配信元ごとに別保存なので、試遊ページの記録はGitHub Pagesには引き継がれません。
